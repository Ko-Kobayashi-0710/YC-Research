## セクター別創業者の特徴

### AGI・AI研究セクター
- **スターアカデミック多数**: Yale教授、Google Brain出身、Keras創始者
- 既に多額調達済みの状態でYC入り（Ndea $43M）
- 「論文→商業化」のスピードが過去最速

### ハードウェア・物理セクター
- 出身: Tesla, SpaceX, Apple（「物を作ったことがある人」）
- YC歴史的に珍しい「実物バックグラウンド」の創業者が増加
- 防衛・宇宙系はNASA/政府機関の専門家

### Healthcare・Biotech
- 医師＋エンジニアのデュアルバックグラウンドが増加
- 製薬会社・病院・研究機関出身
- Stanford医学部・Harvard Medical School出身が目立つ

### AI Agent（垂直特化）
- Amazon・Meta・McKinsey出身が多い
- 「大企業の内部問題を解決した経験」が出発点
- 業界経験（医療・法律・建設）と技術力の組み合わせ

### Fintech
- Apple・Google・Stripe出身が多い
- 規制業種（金融）の実務経験者が増加（ゼロファウンダーなし）

## API設定について

**APIキーの設定方法**（Anthropic APIを使った自動タグ付けを有効化するため）:

```bash
# ~/.claude/settings.json に追加:
{
  "env": {
    "ANTHROPIC_API_KEY": "sk-ant-your-key-here"
  }
}
```

セッション再起動後、`scripts/` ディレクトリのタグ付けスクリプトが使用可能になります。
