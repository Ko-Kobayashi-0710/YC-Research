## フレーミングの変化（「何を作っているか」の言語変化）

| バッチ | 支配的フレーミング | 象徴的ワード |
|--------|-------------------|-------------|

| S23 | 「AI for 〇〇」 | AI for X |
| W24 | 「〇〇の自動化」 | Automate, AI assistant |

| W25 | 「エージェントで〇〇を実行」 | Autonomous, Deploy agents |
| X25 | 「Cursor for 〇〇」 | Agentic, AI-native |
| S25 | 「〇〇の完全自動化」 | End-to-end, Replace |
| F25 | 「エージェントフリート」 | Fleet, Orchestration |
| **W26** | **「〇〇ワークフローのAI（高精度・監査可能）」** | **Accuracy, Audit-ready, Mission-critical** |

### 「Copilot」の消滅
```
W23: ~4%のスタートアップが「Copilot」フレーミング使用
W24: 3%
W25: <1%（消滅）
W26: <0.5%（完全消滅）
```
**「Copilotは補助する。Agentは実行する。」** — この転換がW25〜W26で完成。

## 業務の「危険度」によるAIの分類進化

```
Phase 1 (W23-S23): 「やって当たり前の定型業務」のAI化
                   → データ入力、スケジューリング、メール返信

Phase 2 (W24-S24): 「判断を要する業務」へのAI進出
                   → 法律レビュー、採用判断サポート、会計

Phase 3 (W25-X25): 「自律実行型エージェント」の本格展開
                   → 人間の確認なしに実行するエージェント群

Phase 4 (S25-F25): 「エージェント群の管理・監視」が課題化
                   → エージェントインフラ成熟フェーズ

Phase 5 (W26):     「失敗すると命取りの業務」への侵入
                   → 医療診断・金融犯罪・防衛・航空整備
                   → Accuracy, Auditability, Compliance が差別化要素
```

**W26が重要な理由**: Phase 5に到達したということは「AIの信頼性が実用レベルに達した」ことを意味する。

## W26が示す「次の波」の予告

### 波1: エージェント経済の金融インフラ
Maven（音声AI決済）、Sponge（エージェントウォレット）、Orthogonal（エージェント向けAPI課金）が同時登場。
→ **AIエージェントが自律的にお金を使う時代の基盤整備**が始まった。

### 波2: ハードウェア＋AI = 「作れないモートの構築」
Pocket（AIハード）、Voltair（ドローン網）、RoboDock（自動運転デポ）。
ソフトウェアだけでは複製できない参入障壁。

### 波3: AGI商業化の前哨戦
Ndea（$43M）、Confluence（97.9%スコア）、ARC Prize（OpenAI/Anthropic採用ベンチマーク）。
→ **2026〜2027年が「AGI実用化元年」になる可能性**の布石。

### 波4: 規制産業の本格開放
医療（22社）、法務（4%）、防衛（~7%）。
→ 「リスクが高いから参入しない」から「リスクが高いから高いモートになる」へ価値観転換。
