# Note記事執筆スタイルガイド（YC・スタートアップ分析系）

## 基本哲学
「読まれる記事」ではなく「保存される記事」を書く。
読んで終わりじゃなく、後で見返したくなる解像度を持たせる。

---

## 構成ルール

### 1. ファーストビューで「誰向けか」を明確にする
- 冒頭3行以内に「この記事で何が得られるか」を入れる
- ターゲット読者を想定（VCパートナー、スタートアップ創業者、大企業の事業開発）

### 2. 見出し設計（3階層まで）
- H1：記事タイトル（疑問形か「〜した話」形式が強い）
- H2：大セクション（3〜5個）
- H3：個別企業・論点（企業名を前に出す）
- 見出しだけ読んでも「何が書いてあるか」分かる設計

### 3. 段落は3〜4行以内
- 日本語Web読者は長い段落を読み飛ばす
- 1段落＝1メッセージ
- 次の段落との接続は「だから」「一方で」「面白いのは」で繋ぐ

### 4. 「投資家目線の解説」を必ず入れる
- 事実の説明で終わらない
- 「これは何を意味するか」「なぜ今このタイミングか」「日本でどう使えるか」を添える
- 1企業紹介につき1行の「投資メモ」を入れる

### 5. 数字は具体的に
- 「速くなった」→「5分→30秒（83%削減）」
- 「大きい市場」→「$300B（養殖水産業）」
- 数字がない場合はスケール感を言語化する

### 6. 感情的フック（冒頭・中盤・末尾）
- 冒頭：「え、こんな会社が?」という意外性
- 中盤：具体的な現場の痛みを描写
- 末尾：「だから自分はこう思う」という個人の意見表明

### 7. 禁止ワード
- 「〜となっています」「〜と言えるでしょう」（他人事感が出る）
- 「画期的な」「革命的な」（使いすぎで読者が慣れている）
- 「〜することができます」（「〜できる」で十分）

### 8. 締めの型
「XはYだった。だから私はZを見ていく。」という個人の意志表明で終わる。
分析記事として終わらず、「次に何をするか」を示す。

---

## スタートアップ紹介の定型フォーマット

```
### [企業名]（カテゴリ）
[1行で何をする会社か]

**課題**：[従来の問題を現場目線で描写]
**解決策**：[何がどう変わるか・数字で]
**なぜ今か**：[技術・規制・市場の変化]
**投資メモ**：[Moat・市場規模・懸念点を1〜2行]
```

## トーン設定
- 一人称は「私」または「僕」（Ko Kobayashi個人の視点）
- 断言する（「〜だと思う」より「〜だ」）
- 他のVCや分析と差別化する観点を1つは入れる
